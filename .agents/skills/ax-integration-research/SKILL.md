# ax-integration-research

GWS/API/MCP 연동 조사: 공식 문서, 인증, 최소 권한, 이벤트 일관성, 대안 및 검증 방법을 기록한다. 실제 회사 데이터 접근 금지.

1. 해당 태스크와 관련된 소수 문서만 읽는다.
2. 확인된 근거와 가정을 구분한다.
3. 결과는 요약/근거/리스크/결정 요청 순으로 기록한다.
4. 다른 에이전트에게 자동 재위임하지 않는다.
