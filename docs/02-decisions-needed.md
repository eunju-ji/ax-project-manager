# 미결정 사항 (승인 전 가정 금지)

| ID | 의사결정 | 권고 초안 | 상태 |
|---|---|---|---|
| D-01 | 관리 대상 | AX팀 파일럿, 전사 확장 가능 모델 | 승인 → ADR-001 |
| D-02 | 리소스 단위 | 주별 인력 계획 공수/확인 공수/잔여 공수 | 승인(건수 MVP) → ADR-002 |
| D-03 | Task 계층 | Project > Workstream > Task > Activity | 승인(3단계) → ADR-003 |
| D-04 | 완료 권한 | 담당자 완료 제안 + 책임자 승인 | 승인 → ADR-006 |
| D-05 | 데이터 연동 | 권한 있는 Drive/Calendar 우선 | 미결정 (OD-05, M1 조사 후) |
| D-06 | AI 대화 | 원문 자동 수집 제외, 선택적 요약/산출물만 | 승인 → ADR-005 |
| D-07 | 개인정보 접근 | 최소 권한·감사·보존기간 정책 선확정 | 원칙 승인 → ADR-007 |
| D-08 | 공수 측정 | 이벤트 횟수로 시간 추정 금지; 수기확인 우선 | 승인 → ADR-002 |
| D-09 | 기술 스택 | 실사용 환경 제약 조사 후 결정 | 미결정 (OD-09, PoC 후) |
| D-10 | 배포/승인 | 합성 데이터 PoC 후 운영 접속 별도 승인 | 승인(게이트) → ADR-010 |

에이전트는 각 항목에 대안 2~3개, 영향, 추천안, 검증 방법을 기록한 후 사용자에게 묶어서 승인 요청한다.

> 2026-11-19: legacy 이관 검토 결과를 반영해 `docs/migration/open-decisions.md`(OD-01~15)로 통합 관리한다. 확정 내용은 `docs/decisions/`가 기준이다. 표의 "권고 초안" 열은 원래 초안이며, 승인된 내용은 ADR이 우선한다(예: D-03은 Workstream 없이 3단계).
