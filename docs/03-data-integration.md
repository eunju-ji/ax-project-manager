# 연동 후보와 검증 방법

| 소스 | 목적 | 권고 MVP | 검증 요소 |
|---|---|---|---|
| Drive/Docs | 문서 산출물·변경 증빙 | 제한 범위 | 변경 API, 파일 권한, 이벤트 중복제거, 삭제·이동 |
| Calendar | 일정·회의 증빙 | 제한 범위 | 참석자 공개 범위, 반복 일정, 변경 알림 |
| Google Chat | 프로젝트 논의 | 후속 | Space 접근 권한, 메시지 공개·보존 정책 |
| Gmail | 요청·승인 근거 | 후속 | 지정 라벨/메일만, 개인정보·동의 |
| Claude/ChatGPT | AI 활용 증빙 | 수동 요약 또는 산출물 링크 | 공식 Export/API 제공 범위, 이용 정책 |
| Git/GitHub | 코드·PR 증빙 | 개발 관련 작업 | 작성자/리뷰어, 커밋-태스크 연결 |

**연계 우선순위**: 공식 API/Webhook → 주기적 API 조회 → 공식 Export → 승인된 RPA. MCP는 개발 에이전트의 도구 접근 방식이며 백엔드 운영 데이터 동기화 그 자체를 대체하지 않는다.

**필수 기능**: 재시도, 페이지네이션, 중복제거, 동기화 지점(checkpoint), 소스 권한 변화, 데이터 삭제 전파, 감사기록, 수집 범위 표시.

**금지**: 승인 없이 조직 전체 메일/개인 채팅 원문 수집 또는 실제 사용자 데이터로 테스트.
