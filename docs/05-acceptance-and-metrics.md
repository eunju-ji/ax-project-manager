# 검증 및 완료 기준

## Task 완료 기준
1. 담당자 및 산출물 지정
2. 완료 조건에 따른 증빙 제출/연결
3. 자동검증 가능한 항목 테스트 통과
4. 상태 변경 이력 및 승인 기록 저장
5. 사용자 검토가 필요한 경우 승인 전 자동 완료 금지

## 파일럿 검증 목표(제안, 확정 아님)
- 허용된 데이터 소스 2개 이상 연계 시연
- 동일 외부 이벤트 중복 생성 0건
- 매핑 제안을 사용자가 수정·거절·재연결 가능
- 담당자별 계획/확인 공수와 잔여 예상 공수 구분
- 허가 없는 자료 접근 0건
- 프로젝트/태스크별 수집 근거 추적 가능

자동 매핑 정확도 목표는 실제 샘플 분포·라벨링 가능성을 확인한 후 합의한다.

## 에이전트 구현 완료 조건
관련 테스트 통과, 요구사항 검증, critical/high 결함 0개, 증빙과 변경내용 문서화, 승인 조건 준수. 실패 시 최대 3회 수정하고 막히면 에스컬레이션.
