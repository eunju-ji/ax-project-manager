# 단계별 추진

1. Discovery: 이해관계자, 실무 흐름, 연동 허용 범위, 우선순위 조사
2. Design: PRD, 데이터 모델, API/권한, 태스크 구조, 화면 플로우
3. Review gate: 독립 검토 1회, 미결정사항 묶음 보고, 사용자 승인
4. MVP: 합성 데이터 기반 프로젝트/태스크/증빙/공수 관리
5. Integrations: 승인된 GWS 소스의 제한적 연결과 동기화
6. Pilot: 실제 승인 사용자로 정확도, 사용성, 보안 검증

한 번에 전체를 개발하지 않고 승인된 Task 단위로 Build → Test → Review → Fix 반복.
