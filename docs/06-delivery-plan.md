Discovery → Design → 로컬 PoC(M0~M3) → 실데이터 파일럿(M4, 11/19~) → 출처 확장·판별 기준 정비(11/23~24) → 회의 반영(11/24, ADR-023).

## 전체 완성 기준 (12/15)
1. 팀원 3명이 공개 주소에서 각자 Google 계정으로 로그인해 쓴다.
2. 팀원 각자의 Google(동의한 것)·GitHub가 연결되어 자동 수집·판별되고, 같은 기록은 한 번만 센다.
3. 첫 화면이 핵심 프로젝트마다 세 질문에 답한다(이번 주 예정·지원 요청 포함).
4. 12/15 주간회의를 관리장 화면으로 진행한다.
5. 운영 문서와 보안 검토가 끝나 있다.

## 진행 방식
- 승인된 태스크 단위로 Build → Test → Review → Fix를 반복한다. 보안·권한 변경은 독립 검토를 거친다.
- 작업 브랜치 Push까지 하고 main 병합은 사용자가 한다.
- 범위 밖(3주 이후): 공수(시간), 프로젝트별 공개 범위, 전사 확장, 단계 지도 보고용 보기.
