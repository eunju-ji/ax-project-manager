# Paseo 프로필 3개 — 생성 시 입력값

| 프로필 | 공급자 | 권장 Thinking | 모드 | 사용 조건 |
|---|---|---|---|---|
| AX-Lead | Claude Code (사용 가능 모델) | Medium, 중요 기획만 High | 기획/작업 관리 가능한 모드 | 기본 총괄, 기획·설계·통합. 단순 결과 취합 시 다른 에이전트를 호출하지 않음 |
| AX-Builder | Codex (사용 가능 모델) | Medium | 승인된 파일 수정 가능한 범위 | 승인된 태스크 구현·테스트. 추가 위임 금지 |
| AX-Reviewer | Codex (사용 가능 모델) | Medium | 읽기 전용/Auto-review 가능한 범위 | 설계와 diff 독립 검토. 파일 변경·추가 위임 금지 |

'When to use'에는 각 행의 사용 조건을 복사해 넣는다. 실제 UI의 모델명 및 권한 모드 표시는 설치 버전/프로바이더에 따라 달라지므로 지원되는 옵션을 선택한다.

AX-Lead를 기본 실행하고 분명한 이유가 있을 때만 나머지 프로필을 생성한다. 네트워크·외부 명령과 외부 데이터 쓰기 권한은 별도 승인한다.
