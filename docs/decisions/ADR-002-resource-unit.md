# ADR-002 리소스 단위: MVP는 작업 내역 건수

- 상태: 승인 (2026-11-19) · 출처: OD-02, D-02, D-08, Q10
- 결정: MVP의 리소스 현황은 **작업 내역 건수**(고유 WorkLog ID 기준)와 참여 프로젝트·업무 유형·확인 요청 집계로 제공한다. 공수(계획/확인/잔여)는 사람이 입력·확인하는 별도 기록으로 후속 도입한다. 이벤트 수로 시간을 추정하지 않는다.
- 함께 바뀌는 것:
  - `docs/01-product-brief.md` §6·§8의 공수 항목 → 후속
  - `docs/05-acceptance-and-metrics.md`의 "계획/확인 공수와 잔여 공수 구분" → 후속. "데이터 소스 2개 이상 연계"는 유지
  - `tasks/backlog.md` DES-02·DEV-03 재정의
- 화면에 명시할 한계: 작업 내역 1건의 규모 차이. 공동 작업은 실행자별 1건, 팀 합계는 고유 WorkLog. 집계 주는 실행 시각 기준이고, 실행 시각을 모르면 별도로 표시한다.
- 참고: `AGENTS.md` §1의 "계획 공수·실제 공수·가용량 관리" 목표는 후속 단계 목표로 해석한다.
