# ADR-003 업무 계층

- 상태: 승인 (2026-11-19) · 출처: OD-03, D-03
- 결정: 프로젝트 > 태스크 > 작업 내역의 3단계로 하고, 태스크는 공통 업무 유형 5종(기획·설계 / 조사·분석 / 제작·구현 / 검증 / 운영·지원) 속성으로 묶는다. Workstream은 도입하지 않는다.
- 신규 초안의 Activity(발생 이벤트)는 계층이 아니라 근거 쪽 엔터티(ADR-004 SourceEvent)로 다룬다.
- 재검토 조건: Workstream이 필요한 실제 사례가 확인되면 선택 속성으로 확장을 검토한다.
