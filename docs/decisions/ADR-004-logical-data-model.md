# ADR-004 논리 데이터 모델 방향

- 상태: 승인(방향) (2026-11-19) · 출처: OD-04, Q04, Q08
- 결정: 논리 엔터티는 Project, Task, WorkLog, Source(원본 객체, 키 = 서비스+계정 범위+원본 ID), SourceEvent(발생 이벤트·버전), Link(업무↔근거, 다대다, 역할·근거·확인 상태), Review, History, AccessAudit로 한다. Effort는 ADR-002에 따라 후속으로 둔다.
- 이벤트 보존 계약: 이벤트 식별자, 발생 시각, 수집 시각, 실행자(확인/미상 구분)를 보존한다. SourceEvent를 별도 엔터티로 둘지 Source의 버전 행으로 둘지는 M1에서 결정한다.
- ID는 행 번호·화면 순서와 무관한 불변 ID로 하고, 원본 식별 키와 관계 키를 분리한다.
- 쓰기 계약 기대 결과(M2 PoC 검증 대상):
  - 같은 실행 ID로 재시도하면 한 번만 적용된다(멱등성)
  - 읽은 뒤 다른 쪽이 수정했으면 덮어쓰지 않고 충돌로 표시한다
  - WorkLog·Link·History 중 일부만 저장되면 감지해 표시한다
- 제외: 물리 저장소와 스키마는 OD-09에서 결정한다. 화면 JSON은 어댑터 출력 형식일 뿐 운영 스키마가 아니다.
