# ADR-006 완료 판단과 승인

- 상태: 승인 (2026-11-19) · 출처: OD-07, D-04, Q09
- 결정: LLM은 근거와 함께 완료를 제안만 한다. 담당자가 판단(완료 제안)하고 프로젝트 책임자가 확정한다. 판단자·시각·변경 전후·근거를 History에 남긴다. 화면은 "판단함"과 "저장 성공/실패"를 구분해 표시한다.
- 예외 처리(M1에서 상태 전이 계약으로 상세화):
  - 담당자가 곧 책임자인 경우: 자기 승인을 허용하되 History에 표시한다
  - 책임자가 부재한 경우: 대리 확정자를 지정한다
  - 재판단: 완료를 진행 중으로 되돌릴 수 있고 이력은 보존한다
  - 동시 판단: 덮어쓰지 않고 충돌로 표시한다
