# ADR-007 정보 보호 원칙

- 상태: 승인(원칙) (2026-11-19) · 출처: OD-08, D-07, Q02, Q05
- 결정:
  - 원문뿐 아니라 제목·작성자·요약·History의 변경 전후 값도 보호 대상이다
  - 공통 현황, 보존 메타, 요약, History 각각의 열람·보존·삭제 범위를 정한다
  - 공통 데이터 접근 감사(AccessAudit)를 둔다
  - 사람별 리소스 지표를 감시나 성과 평가 근거로 쓰지 않는다. 이 목적 제한을 사용자에게 고지한다
- G2 전에 정할 세부: 개인 계정으로 읽은 내용의 팀 공유 범위, 공통 허브 쓰기 계정, 보존 기간, 권한 상실 시 숨길 항목.
