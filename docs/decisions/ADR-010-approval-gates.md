# ADR-010 단계별 승인 게이트

- 상태: 승인 (2026-11-19) · 출처: OD-13, D-10, AGENTS.md §9

| 게이트 | 허용 범위 | 선행 승인 |
|---|---|---|
| G0 로컬 합성 데이터 | 로컬 코드·테스트·합성 데이터, 외부 쓰기 없음 | 해당 구현 태스크 승인 |
| G1 외부 시험 환경 쓰기 | 시험용 Sheets 생성·쓰기, Apps Script 등 시험 배포. 합성 데이터만 | 사용자 별도 승인(계정·범위 명시) |
| G2 시험 사용자 데이터 | 동의한 시험 사용자의 승인된 소스·범위만 읽기 | ADR-007 세부 확정 + 사용자 승인 |
| G3 운영 배포 | 운영 환경 배포·실사용자 접속 | 파일럿 결과 보고 후 사용자 승인 |

- 앞 게이트의 승인은 다음 게이트를 포함하지 않는다.
- 현재 위치: G0 (M0·M1 진행).
