# ADR-012 원본(Source)과 발생 이벤트(SourceEvent) 분리 저장

- 상태: 승인 (2026-11-19) · 출처: ADR-004 하위 결정 · 근거: `docs/design/m1-01-logical-model.md` §1·§2.1
- 결정: 원본 객체(Source)와 그 원본에서 일어난 이벤트(SourceEvent)를 별도 엔터티로 저장한다. Source의 버전 행으로 이벤트를 표현하는 대안은 채택하지 않는다.
- 이유:
  - 원본이 삭제·이동·접근 불가가 돼도 이벤트와 그에 연결된 작업 내역이 남는다(L02).
  - 이벤트 단위로 실행자·발생 시각을 보존하고 서로 다른 업무에 연결할 수 있다.
  - Drive 활동 기록과 GitHub 커밋·PR이 이벤트 단위로 제공된다(ADR-011).
- 규칙: 이벤트 키는 서비스별 규칙과 정규화(`key_version`)를 따른다. 같은 키에 내용이 다르면 둘 다 보존하고 충돌 검토로 보낸다(m1-01 §2.1).
- 화면 영향: 없음. 이벤트는 작업 내역·관련 자료의 근거로만 쓰인다.
