# ADR-013 데이터 원본은 트랜잭션 DB, Sheets는 조회용 사본

- 상태: 승인 (2026-11-19) · 출처: OD-09, 사용자 전환 기준 · 근거: `docs/design/m2-storage-direction.md`, `docs/migration/m2-local-report.md`
- 결정:
  - 업무 데이터의 원본은 여러 행을 한 트랜잭션으로 저장할 수 있는 관계형 DB다.
  - Google Sheets는 DB에서 한 방향으로 내보내는 **읽기 전용 조회·공유 사본**이다. Sheets를 고쳐도 원본은 바뀌지 않고, 판단·교정은 화면에서만 한다.
  - OD-09 (A) Sheets 단독 운영은 후보에서 제외한다.
- 이유: Sheets식 저장소(행 단위 쓰기만 원자적) 위에서 로컬 PoC를 3회 수정·재검증했지만 모두 fail이었다. 결함이 반복된 영역은 여러 행 원자성 부재를 메우려고 만든 예약·보정·격리 코드였다.
- 해석 갱신: legacy P8 "LLM이 판단 · 공통 Sheets가 보관 · 화면이 조회/검토"는 "LLM이 판단 · **DB가 보관** · Sheets와 화면이 현황 공유 · 화면이 검토"로 읽는다.
- 유지: ADR-002·004·006·007·010·012. 같은 요청 중복 방지, 버전 충돌, 감사 기록, 판정 결과 표시는 DB에서도 필요하다.
- DB 제품·배치는 `docs/design/m3-data-architecture.md`와 ADR-014(예정)에서 정한다. 비용이 드는 인프라는 별도 승인(AGENTS.md §9).
