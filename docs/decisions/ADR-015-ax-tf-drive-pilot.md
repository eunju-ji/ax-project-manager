# ADR-015 실데이터 파일럿: 공유 드라이브 AX-TF (G2 범위)

- 상태: 승인 (2026-11-19) · 출처: 사용자 지시 "테스트 후 바로 Google Workspace 연동, 실제 데이터로 시작, 드라이브는 공유 드라이브 AX-TF만" · 근거: `docs/design/m4-drive-ax-tf-pilot.md`
- 결정:
  1. **대상**: 공유 드라이브 AX-TF 하나. 다른 드라이브·개인 드라이브·Gmail·Calendar·Chat 제외. Drive에는 쓰지 않는다.
  2. **인증**: 사내 전용(Internal) OAuth, AX-TF 멤버인 팀원 1명 계정. 스코프 `drive.metadata.readonly`, `drive.activity.readonly`. 토큰은 이 PC의 Git 제외 폴더에만 둔다. 비밀값은 채팅으로 주고받지 않는다.
  3. **저장소**: 이 PC의 로컬 SQLite로 시작한다(M3 설계의 "G2 전 PostgreSQL" 조건에 대한 예외). 근거: Drive 데이터는 다시 수집할 수 있고 사람 판단 기록만 옮기면 된다. 조건: 판단 기록 내보내기·가져오기 스크립트를 첫 수집 전에 준비, PostgreSQL 이관(M3-03)은 파일럿과 병행.
  4. **저장 범위**: 파일 ID·이름·종류·폴더 경로·생성/수정 시각, 활동(행위자·동작 종류·시각). 파일 내용·댓글 본문·공유 대상 목록은 저장하지 않는다.
  5. **팀원 범위**: 실제 팀원은 3명이 아니다. 팀원 목록은 실제 활동 행위자와 공유 드라이브 멤버에서 만든다. 합성 데이터의 3명 규칙은 로컬 예시 데이터에만 적용한다.
  6. **열람**: AX팀. 보존: 파일럿 기간 동안, 종료 시 삭제 여부 결정.
  7. **팀원 고지**: 사용자 판단으로 별도 고지하지 않는다.
- 파일 내용 없이 계층(프로젝트·태스크·작업 내역)을 특정할 수 있는지는 §판별 단계로 확인한다:
  - 1단계: 메타데이터(폴더 경로·파일 이름·행위자·시각)만으로 연결을 제안하고, 모든 연결은 사람이 검토함에서 확정한다(ADR-008, m1-03). 첫 2주 데이터로 "자동 제안이 맞은 비율 / 사람이 고친 비율 / 판단 불가 비율"을 측정한다.
  - 2단계(측정 결과가 부족할 때만, 별도 승인): 판별 시점에만 문서 앞부분을 읽어 쓰고 저장하지 않는 방식. `drive.readonly` 스코프가 필요해 범위가 넓어지므로 다시 승인받는다.
- 행위자 이름 매핑: Drive Activity의 `people/…` ID와 Drive 메타데이터의 사용자 정보(이름·이메일·permissionId)를 대조해 만든다. 대조가 안 되면 디렉터리 조회 스코프 추가를 별도로 검토한다(첫 수집에서 검증).

- 2026-11-19 보안 재검토 대응: 누락 source 재확인, 조상 경로 비노출, .pilot/exports/*.jsonl ACL 검사·덮어쓰기 거부, CSV UTF-8/경로/무손실 인코딩, 공용 키 규칙을 구현했다. 실수집 게이트는 아직 보류: 전체 서버 테스트 정리 순서 EPERM 및 build Python 실행 환경 미해결. 상세 검증은 m4-drive-connector-report.md의 보안 검토 대응 절 참조.

## 변경 (2026-11-19, 사용자 승인): 첫 확인은 Apps Script 내보내기로
- 사유: 회사 GCP 프로젝트 권한을 당장 받기 어렵다.
- **수집 방식 A(임시)**: 사용자 회사 계정으로 script.google.com에 스크립트를 만들어 웹 앱으로 배포한다(실행: 나, 접근: 나만). 스크립트는 같은 두 스코프(`drive.metadata.readonly`, `drive.activity.readonly`) + 외부 요청 권한(`script.external_request`)으로 Drive·Drive Activity REST API를 커넥터와 **같은 fields 마스크**로 호출하고, 원 응답 페이지를 JSON으로 내려 준다. Drive에는 쓰지 않는다. 같은 회사 계정 소유 스크립트라 Google 검증이 필요 없다.
- 받은 JSON은 `app/server/.pilot/imports/`(ACL 보호)에 두고 `drive:import`로 기존 커넥터 처리 과정(드라이브 범위 검사·분해·중복 방지·사람 대조)에 그대로 재생해 넣는다. 가져온 뒤 원본 JSON 삭제를 기본으로 한다.
- 범위: 사용자 본인 확인용. 다른 팀원에게 화면을 보여 주기 전에 보안 재검토 3회차의 남은 high 2건(접근 불가 상위 폴더 경로 노출)을 해결한다.
- 회사 GCP 프로젝트 권한을 받으면 원래 방식(사내 OAuth 커넥터)으로 바꾼다. 데이터 형식은 같다.


> 2026-11-19 ADR-017로 일부 변경: 소스를 Drive·Gmail·Chat·GitHub로 넓히고, 내용은 읽되 원문 대신 핵심(digest)만 저장한다. 해당 항목은 ADR-017이 우선한다.
