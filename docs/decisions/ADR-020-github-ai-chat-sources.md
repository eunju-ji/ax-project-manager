# ADR-020 GitHub·AI 대화 기록 연결

- 상태: 승인 (2026-11-24, 사용자 지시: "내 깃허브도 연결해줘. 내 chatGPT, 내 claude 채팅을 어떻게 연결할지 생각하고 구현해줘.")
- 관계: ADR-005(AI 대화 원문 자동 수집 제외)를 이 문서로 구체화한다. 원문을 저장하지 않는다는 원칙은 그대로이고, 제목·시각·건수 같은 색인과 160자 이하 요약만 남긴다(ADR-017).

## 1. GitHub
- **연결 방식**: GitHub REST API로 사용자 계정의 저장소·커밋·PR·이슈를 읽는다. 토큰이 없으면 공개 저장소만(시간당 60회 제한), 환경 변수 `GITHUB_TOKEN`(읽기 전용, fine-grained)이 있으면 비공개 저장소까지 읽는다. 토큰은 저장소·데이터셋·로그에 남기지 않는다.
- GitHub MCP(plugin:github)가 인증 오류로 연결되지 않아(2026-11-24) API를 직접 쓴다. MCP가 고쳐지면 같은 색인 형식으로 바꿔 끼운다.
- **가져오는 것**: 저장소 이름, 커밋(SHA·제목 첫 줄·시각·브랜치), PR·이슈(번호·제목·상태·생성/병합/종료 시각), 링크. diff·본문·댓글 원문은 저장하지 않는다.
- **판별**: 커밋·PR은 무언가를 만든 기록이라 작업 내역 후보다. 같은 PR에 속한 커밋은 한 작업 내역으로 묶는다(PR이 없으면 하루·브랜치 단위). 병합 커밋, 버전 올리기, 서식만 바꾼 커밋은 작업 내역이 아니다(ADR-018 §10).
- **범위**: 설정 `state.github.login`, 대상 저장소 `state.github.repos`(비어 있으면 최근 90일 안에 push가 있는 계정 저장소 전체).

## 2. AI 대화
| 출처 | 연결 방식 | 이유 |
|---|---|---|
| Claude Code | 이 PC의 세션 기록(`~/.claude/projects/<작업 폴더>/*.jsonl`)을 읽는다 | 로컬 파일이라 자동으로 읽을 수 있다 |
| claude.ai | 설정 › 개인정보 › 데이터 내보내기로 받은 파일을 `app/server/.real/imports/claude/`에 둔다 | 대화 목록을 읽는 공식 API가 없다 |
| ChatGPT | 설정 › 데이터 제어 › 데이터 내보내기로 받은 파일을 `app/server/.real/imports/chatgpt/`에 둔다 | 대화 목록을 읽는 공식 API가 없다 |

- 내보내기는 사용자가 직접 받아 넣는 수동 단계다. 화면이나 문서에서 "자동 수집"이라고 부르지 않는다(ADR-005).
- **색인만 만든다**: 수집기는 대화마다 제목, 시작·마지막 시각, 메시지가 오간 날짜와 건수, (Claude Code는) 작업 폴더·브랜치·수정한 파일 경로만 `inbox/`에 쓴다. 메시지 본문은 쓰지 않는다.
- **판별**: 정기 수집 에이전트가 색인을 보고 기존 프로젝트·태스크와 맞는 대화만 고른다. 필요하면 원본(내보내기 파일·세션 기록)을 읽어 판단하되 저장은 160자 이하 요약만 한다. 대화는 "무엇을 만들었거나 분석·결정했는가"가 드러날 때만 작업 내역이다. 질문만 하고 끝난 대화, 개인적인 대화, 업무와 관계없는 대화는 기록하지 않는다.
- **사람**: AI 대화는 연결한 본인(사용자)의 기록으로만 쓴다. 다른 사람의 대화는 그 사람이 직접 연결해야 한다.
- **링크**: claude.ai는 `https://claude.ai/chat/<id>`, ChatGPT는 `https://chatgpt.com/c/<id>`. Claude Code 세션은 로컬 기록이라 링크가 없다.

## 3. 데이터
- 근거 자료 `kind`에 `commit`·`pull_request`·`issue`·`ai_chat`을 더한다. 폴더 경로가 없는 자료로 다룬다.
- 링크 허용 호스트에 `github.com`, `claude.ai`, `chatgpt.com`을 더한다.

## 4. 수집 제외
- `state.excluded`에 제외할 프로젝트·사람·Chat 스페이스를 둔다. 정기 수집은 여기 있는 스페이스를 읽지 않고, apply-delta는 제외 대상과 연결된 기록을 받지 않는다.
- 2026-11-24 사용자 지시("삼성 대시보드 관련된 내용은 빼줘. 삼성 대시보드에만 관련된 사람들도 빼줘")로 삼성 대시보드 프로젝트와 그 Chat 스페이스, 그 프로젝트에만 관련된 사람을 제외하고 기존 기록을 지웠다. 이때 변경 이력에도 내용이 남지 않도록 지운다(purge).
