AX팀 운영·업무 기록은 위 탭으로 별도 페이지. 업무 기록 탭 구성은 A와 같다(요약 → 태스크 상세 표 + 상태 필터).

② 프로젝트별 점검오른쪽 패널 한 장에 세 질문(지금 단계 태스크 / 다음 / 지원 필요)과 파일

장점

  • 프로젝트마다 세 질문이 한 장에 모여 ②가 빠르다(프로젝트당 2분)
  • 운영 항목이 완전히 분리된다

단점

  • 모든 프로젝트의 세부를 한눈에 비교하기는 어렵다
  • 좁은 화면(태블릿·모바일)에서는 목록과 패널을 오가야 한다

안 C. 단계 보드 — 단계를 열로, 프로젝트를 카드로

①을 가장 강하게 보여 주는 안. 열이 상위 단계, 카드가 프로젝트(지금 단계 위치). 카드를 누르면 드로어에서 ②(태스크·다음·지원·파일). 아래에 이번 주.
