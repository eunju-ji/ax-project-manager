# 주간회의 활용 시나리오 (1단계 ①)

> 2026-11-25 · AX-Lead · 근거: 피드백 정리 261124(팀장님·본부장님), 회의록 261124
> 본부장님 지시대로 **데이터가 아니라 회의에서 관리장을 쓰는 순서**에서 출발한다. 이 시나리오가 레이아웃(2단계)과 데이터 점검(3단계)의 기준이다.

## 1. 장면
- **언제**: 매주 화요일 AX팀 주간회의(본부장·팀장·팀원 2~3명), 약 30분.
- **어떻게**: 한 사람이 관리장 화면을 화면 공유로 띄우고, 위에서 아래로 내려가며 프로젝트를 하나씩 점검한다.
- **목적**: 프로젝트별 **진행 단계·이슈·다음 할 일**을 정기적으로 확인한다. 기능 탐색이 아니라 진척도 파악이다.

## 2. 회의 순서와 화면에서 확인할 질문
| 순서 | 시간 | 보는 곳 | 확인할 질문 | 화면이 보여 줘야 할 것 |
|---|---|---|---|---|
| ① 전체 현황 | 3분 | 첫 화면 맨 위: 핵심 프로젝트 목록 | 어느 프로젝트가 어느 단계인가? 늦어진 곳은? | 프로젝트마다 상위 단계(리서치·기획·프로토타입·개발·테스트·출시·운영)와 진척률, 이슈 표시(지연·확인 필요·도움 필요). 운영 항목은 섞이지 않음 |
| ② 프로젝트별 점검 | 15분 | 프로젝트를 하나씩 선택 | **어디까지 진행됐나?** 이번 단계에서 끝난 것·진행 중인 것은? | 지금 단계와 그 단계의 핵심 태스크(간결하게), 계획 마감·실제 작업 기간·완료 여부 |
| | | | **다음 단계에 무엇이 필요한가?** | 다음 태스크, 이번 주 예정 일정 |
| | | | **누가 지원해야 하나?** | 지원 요청·막힌 점과 관련자(예: 개발실 협의, 경영지원실 권한) |
| | | | (필요 시) 근거는? | 세부 업무와 관련 파일(한 번 더 누르면) |
| ③ 이번 주 할 일 | 7분 | 이번 주 영역 | 이번 주 누가 무엇을 끝내나? 지원은 누가? | 이번 주 마감·예정 태스크(담당), 지원 요청 목록 |
| ④ 팀 운영 | 3분 | 운영 영역(접힘을 펼침) | 채용·이관·교육·휴가·일정에 공유할 것은? | 운영 항목 목록과 이번 주 일정 |
| ⑤ 정리 | 2분 | — | 결정 사항·담당·기한 | 회의록이 다음 수집에서 예정 태스크·지원 요청으로 자동 반영됨 |

- 지난주 한 일(업무 요약)은 회의 중 필요할 때만 본다(②에서 근거로). 첫 화면의 주인공은 아니다.
- 화면을 오가는 횟수를 줄인다: ①→②는 같은 화면에서 펼침/선택, ②의 근거는 드로어.

## 3. 회의 밖의 사용 (보조)
| 사용자 | 언제 | 하는 일 |
|---|---|---|
| 팀원 | 회의 전날 | 자기 프로젝트의 단계·다음 할 일이 맞는지 보고, 잘못된 건 화면에서 고침(수정·삭제 저장), 지원 요청 한 줄(결정 시) |
| 팀장 | 수시 | 기간 요약 아래 태스크 상세 표를 상태 필터로 보며 지연·확인 필요 처리 |
| 본부장 | 회의 전 | 첫 화면만으로 프로젝트별 단계와 이슈 확인 |

## 4. 화면 요구사항으로 옮기기
| 요구 | 출처 | 시나리오 단계 |
|---|---|---|
| 핵심 프로젝트 우선, 운영 항목 분리(별도 영역), 별표 | 본부장 | ①④ |
| 상위 단계 먼저, 선택 시 세부 업무·파일 | 본부장 | ①② |
| 태스크는 핵심 위주로 간결하게 | 본부장 | ② |
| 계획 마감·실제 작업 기간·완료 여부·진척률 구분 | 팀장 | ② |
| 이번 주 할 일·지원 요청 | 본부장 | ③ |
| 요약 › 프로젝트 › 태스크 계층, 요약 아래 기간 태스크 상세 표 | 팀장 | 보조 |
| 상태 필터(진행 중·완료 등) | 팀장 | 보조 |
| 화면에서 수정·삭제 저장 | 팀장 | 보조(회의 전 정정) |
| 최하단 요소 제거, 접힘 표시 통일 | 팀장 | 전체 |

## 5. 시나리오가 통과해야 할 검증
- ①만 보고 "어느 프로젝트가 어디까지 왔고 어디에 문제가 있는지" 말할 수 있다.
- ②에서 프로젝트마다 세 질문(어디까지 / 다음 / 누가 지원)에 화면만 보고 답할 수 있다.
- ③에서 이번 주 할 일과 지원 요청을 담당자와 함께 읽을 수 있다.
- 회의 30분 안에 핵심 프로젝트 7개를 모두 훑을 수 있다(프로젝트당 2분 남짓).
