  1. 로그인: 화면은 "Sign in with ChatGPT"로 들어오고, 관리장 초대 목록에 있는 이메일만 입장한다. 회사 워크스페이스 없이 개인 ChatGPT 계정으로 가능하다.
  2. 팀원 수집: 팀원 PC의 수집 도우미가 정해진 시각에 gws-work를 팀원 계정으로 불러 체크포인트 이후 색인을 모은다(파일 이름·작업자·시각, 메시지·메일 제목·보낸 사람·시각). 그리고 사이트 /api/inbox로 보낸다. 판별은 하지 않는다.
    • 실행 수단: gws-work에 예약 호출(CLI·API 토큰)이 있으면 그것을 쓴다. 없으면 팀원 PC의 Claude Code·Codex(또는 Paseo) 예약 실행을 쓴다.
  3. 판별: 사용자 PC의 판별 에이전트가 하루 4번 팀 수집함을 가져와 자기 수집분과 합쳐 판별하고, delta를 사이트에 올린다(/api/ingest/delta).
  4. GitHub: 공개 저장소는 팀원 사용자명만으로 가져온다. 비공개는 팀원의 읽기 토큰이 필요하다.
먼저 확인할 것: ChatGPT 사이트가 ① 사용자 요금제 안에서 무료인지, ② 서버 API(POST)·비밀값·DB를 지원하는지, ③ 다시 배포해도 주소가 그대로인지, ④ Sign in with ChatGPT로 초대한 사람만 들어오게 할 수 있는지. 지금 코드는 Workers 방식이라 그대로 옮길 수 있다. ②가 안 되면 아래 대체안을 쓴다.

②가 안 될 때의 대체안: 사이트를 화면 전용으로 쓴다. 사용자 PC가 판별 결과를 화면용 데이터 파일로 만들어 하루 4번 사이트에 다시 올린다. 팀원 색인은 방안 3의 "공유 폴더 수집함"으로 받는다. 이때 화면에서 바로 수정하는 기능은 쓸 수 없다.

  1. 주소: 이름.workers.dev 고정. 도메인 구입이 필요 없다.
  2. 로그인: Cloudflare Access 이메일 인증 코드(무료 50명까지). 초대한 이메일로 받은 코드를 넣으면 입장하므로 Google OAuth가 필요 없다.
  3. 수집 흐름: 방안 1과 같다. 팀원 수집 도우미 → /api/inbox → 사용자 PC 판별 → delta → D1.
  4. 준비 상태: 1·2단계(핵심/연결부 분리, Workers 연결부, Access 로그인 검증, 수집함, 분할 업로드)는 끝났다. 남은 것은 D1 저장소 연결, 실데이터 이전, 배포(약 1~2일)다.
  5. 무료 한도: 요청 10만/일, 요청당 CPU 10ms(그래서 delta를 200건씩 나눠 보냄), D1 5GB. 2~10명 규모로 충분하다.
ChatGPT 사이트와 같은 실행 방식(Workers)이라, 방안 1을 시험하다 안 되면 코드를 버리지 않고 이쪽으로 바로 옮길 수 있다.

5. 방안 3 · 공유 위임 수집(팀원 설치 없음) + 무료 정적 사이트

팀원 PC에 아무것도 깔지 않고, 팀원이 업무 자료를 사용자와 공유하는 것만으로 수집한다. 수집은 지금처럼 사용자의 gws-work 한 곳에서만 돈다.

  1. 수집: 팀원 자료가 공유 드라이브·공유 Chat 방·참조 메일로 들어오면 사용자의 gws-work가 이미 읽는다. 팀원별 연결·토큰·예약 실행이 필요 없다.
  2. 화면: GitHub Pages(무료, 주소 고정)에 화면을 올리고, 데이터는 브라우저에서 암호를 넣어야 풀리게 암호화해 둔다. 사용자 PC가 판별 후 하루 4번 다시 올린다.
    • 호스팅은 방안 2(Workers + Access)를 그대로 써도 된다. 이 방안의 핵심은 "팀원 쪽 수집을 없애는 것"이다.
  3. 못 가져오는 것: 팀원의 개인 메일(참조하지 않은 것)·개인 드라이브·로컬 AI 대화. 필요하면 팀원이 주 1회 AI 대화 내보내기 파일을 공유 폴더에 넣는다.
주의: GitHub Pages는 공개 주소라 데이터 보호를 암호화에만 기댄다. 사람별 로그인·권한·접근 기록이 없고, 화면 수정도 쓸 수 없다(정적 사이트). 회사 데이터를 공개 주소에 두어도 되는지 내부 확인이 먼저다. 이 점이 걸리면 호스팅만 방안 2로 바꾼다.

검토했지만 뺀 우회안: 사용자 PC + Cloudflare 임시 터널은 주소가 매번 바뀐다. 고정 터널은 도메인 구입(연 1~2만 원)이 필요하고, PC가 꺼지면 화면도 꺼진다.
