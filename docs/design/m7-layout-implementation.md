# m7 화면 구현 기준

2026-11-26 사용자 결정. 배치 기준은 m7-layout-scenarios.html이며, 3안은 후속 지시대로 사람별 리소스 화면으로 변경한다.

- 테마: Linear, Linear · Notion 색상(기본), 2안 · 현황 → 이번 주, 3안 · 사람별 리소스. 삭제되었거나 알 수 없는 저장값은 기본값으로 복구하고 저장한다.
- 2안: 핵심 프로젝트 카드(단계 흐름·이슈·다음·참여), 이번 주·다음 주 표, 통합 일정, 기본 접힘 지난 기록. 참여 비율은 해당 사람의 최근 14일 전체 작업 내역 중 해당 프로젝트의 비율이다.
- 카드: 제목 13px·최대 2줄, 메타데이터 묶음, 패딩 8px·간격 6px. 칸별 기본 5개와 N개 더/접기. 참여 비중이 0인 사람은 제외하며 전원 없으면 —.
- 3안: 주 이동·담당자 선택, 사람별 현재 업무·다음 주·예정과 투입 비중·새 일 시작 가능일, 좁은 프로젝트 현황 레일. 전체 일정과 지난 기록은 기본 접힘이다.
- 기존 Linear 간트·드로어·상태 점·필터·아바타·진척률과 Notion 색상을 재사용한다. 모래 #faf7f0, 하늘 #eaf1fb, 라벤더 #f5f3fa로 영역을 구분한다.

## 계산 계약

모든 날짜는 기존 model.js의 한국 날짜 변환을 사용한다. 합쳐진 태스크와 참고 태스크는 제외하고 완료 상태를 자동으로 바꾸지 않는다.

| 값 | 계산 |
|---|---|
| 투입 비중 | 기준일 포함 최근 14일, 실제 수행자의 날짜가 알려진 작업 내역 수를 프로젝트별로 나눈 비율. 정수 반올림하며 합이 100에서 1 정도 차이 날 수 있다. 분모 0이면 기록 없음. 멈춘 일 제외 |
| 지금 하는 일 | 담당 또는 최근 수행 관계가 있는 미완료 태스크 중 최근 14일 작업·기준 주 계획 겹침·30일 이내 지연에 해당하는 일 |
| 이번 주 | 월~일 마감·계획 겹침 및 최근 14일 작업. 30일 이내 지연을 맨 위에 둔다. 더 오래 지연된 일도 최근 작업이 있으면 포함 |
| 다음 주 | 다음 월~일 마감 또는 계획 기간 겹침. 2안 표에서는 마감 없는 일을 이번 주에만 표시. 3안은 다음 주 시작 예정도 유지 |
| 예정 | 시작일이 다음 주 일요일 이후인 담당 미완료 태스크 |
| 끝나는 날 | 태스크 마감일. 사람은 현재 일의 가장 늦은 마감일. 없으면 종료일 미정. 지난 날짜면 지연 배지 |
| 새 일 시작 가능 | max(현재 일·다음 주 일의 마지막 마감 다음 근무일, 기준일 다음 근무일). 토·일은 다음 월요일. 현재 일에 마감이 없으면 일정 미정 N건, 마감이 지났으면 지연 N건을 함께 표시. 현재 일이 없으면 지금 가능 |
| 멈춘 일 | 현재 일 조건에 해당하지 않고 미래 계획도 없는 미완료 담당 태스크. 기본 접힘이며 투입 비중·시작 가능일에서 제외 |

주를 옮기면 기준일을 7일씩 옮겨 최근 14일과 다음 주를 다시 계산한다. 작업 내역 비중은 시간·공수로 환산하지 않으며 그 기준은 title로 제공한다. 최근 작업이 있는 미래 태스크는 현재와 다음 주·예정에 동시에 해당할 수 있다. 시작일만 있는 계획은 해당 시작 주에만 계획 겹침으로 인정하며, 오래된 시작일을 무기한 진행으로 해석하지 않는다.
