# 구현 상태와 경계

## 실제로 있는 것

- TypeScript·CSS·정적 JSON의 프론트엔드 UI와 독립 실행 HTML.
- 가상 프로젝트 7개, 태스크 23개, 작업 내역 47건, 관련 자료 68개.
- 주간 집계·미리 작성된 설명 문장·업무 유형 분포·담당자 표.
- 프로젝트·태스크 펼침, 관련 자료 스크롤, 최신순 에피소드, 월별 타임라인.
- 태스크 검토에서 완료·진행 중을 선택하는 메모리 상태 처리.
- 설정 및 서비스 연동 예정 화면. 실제 연결 동작은 없음.
- 기본 Linear 구조 + Notion 색상과 총 6개 테마 선택.

김지현·박성진·이수민은 가상 인물입니다. 예시 기준일은 `2026-11-17`이며 오늘 표시도 이 날짜를 따릅니다. 실제 서비스 운영 데이터가 아닙니다.

## 아직 없는 것

| 서비스·데이터 기능 | 상태 |
|---|---|
| 외부 기록 수집·원본 링크 조회 | 미구현 |
| LLM의 동일 업무 판단·분류·요약 갱신 | 미구현. 현재 설명 문장은 샘플에 작성한 문장 |
| 공통 Google Sheets 생성·읽기·쓰기 | 미구현 |
| 작업 내역의 운영용 저장 스키마 | 미확정·미구현 |
| 실제 로그인·개인/팀 권한 | 미구현 |
| 검토·태스크 상태 영속화 | 미구현. 새로고침하면 초기화 |
| 변경 이력·승인자·실행 결과 저장 | 미구현 |
| 자동 실행·동기화·중복 방지·충돌 처리 | 미구현 |
| 원본 이동·삭제·접근 불가 확인 | 미구현 |
| 실제 파일·저장소 열기 | 예시 이미지 미리보기만 제공 |
| 공수·리소스 이용률 | 미구현. 화면은 작업 내역 건수 |

테마 선택만 localStorage에 저장합니다. 같은 화면의 검토 결과를 바꾸는 것은 서버 저장 성공을 뜻하지 않습니다.

## 코드가 서비스 데이터 모델을 확정하지는 않는다

UI 코드의 `Task`는 태스크, `Subtask`는 작업 내역입니다. `subtasks`에 예시 내역이 중첩되어 있습니다. 이 형태를 그대로 Sheets나 DB 스키마로 채택한 것은 아닙니다. `sourceId`는 현재 샘플 내역과 자료를 연결합니다.

현재 스키마는 화면 시연을 위한 최소 정보만 담습니다. 실제 원본의 계정 범위·외부 ID·권한·확인 시각·변경 이력 등의 운영 정보는 아직 없습니다.

## 검증 한계

Node 테스트는 날짜·정렬·집계·HTML 생성·상태·자료 참조를 검사합니다. 서비스 연동·LLM 판단·권한·저장·자동 실행이 검증된 것은 아닙니다. 자동 브라우저의 로컬 파일 접근 제한으로 실제 레이아웃·스크롤·모바일 시각 검증도 완료하지 못했습니다.
