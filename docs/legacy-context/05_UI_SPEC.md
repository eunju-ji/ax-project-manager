# 최신 UI 기준

## 테마와 공통 탐색

- 기본 화면: **Linear 구조 + Notion 색상**(`linear-notion`). Linear의 목록·밀도·레이아웃·모서리를 유지하고 Notion의 색상 토큰만 적용합니다.
- 선택 가능한 6개: Linear, Linear · Notion 색상, Notion, Attio, Airtable, ClickUp.
- 각 테마의 고유 팔레트를 사용합니다.
- 글로벌 사이드바는 없습니다. 로고로 홈 복귀하며 프로젝트 목록에서 해당 프로젝트 아래에 내용을 펼칩니다. Airtable 내부 Views 패널은 예외입니다.
- 상단에는 검토함과 설정 버튼이 있습니다. 인원 아바타를 상단 설정 대신 사용하지 않습니다.
- 프로젝트명은 태스크명보다 크고 굵게 구분합니다. 폴더 아이콘과 프로젝트명 사이에 추가 간격을 둡니다.

## 주간 요약

- 팀 전체가 기본입니다. 김지현·박성진·이수민은 가상 담당자이며 개인별로 선택할 수 있습니다.
- 날짜 드롭다운과 앞뒤 화살표로 주를 바꿉니다. 별도의 ‘이번 주’ 버튼은 없습니다. 월요일~일요일 기준이며 Asia/Seoul로 계산합니다.
- 왼쪽 숫자 / 가운데 설명 / 오른쪽 시각화의 **22 : 43 : 35** 열 비율입니다. 사용자가 넓혀 달라고 한 것은 왼쪽과 오른쪽 영역이며, 가운데 영역은 줄인 상태입니다.
- 고정 높이 안에서 필요한 본문을 스크롤합니다. 데스크톱·태블릿·모바일 높이는 다릅니다. 현재 수치는 CSS를 기준으로 합니다.
- 가운데는 프로젝트별로 무엇을 했는지 설명하는 문장입니다. 작업 내역 목록은 펼쳐서 보며 시간은 항목 옆에 붙입니다.
- 오른쪽에는 업무 유형별 작업 내역 비중과 담당자별 작업 내역·태스크·확인 요청 집계가 있습니다. 시간·공수·가동률 차트가 아닙니다.
- 제목·가운데 설명 크기는 유지했고 나머지 작은 보조 글씨는 14px 중심으로 키웠습니다. 왼쪽은 아이콘·여백·수치 묶음으로 정돈했습니다.
- 주간 요약은 프로젝트 검색·필터와 독립적입니다.

## 프로젝트와 태스크

- 가장 최근 **태스크 생성일** 기준으로 프로젝트를 정렬합니다. 최근 수정일·최신 작업 내역 시간 기준과 다릅니다.
- 프로젝트 유형 구분과 유형 필터는 없습니다. 개발 이후 운영도 같은 프로젝트에서 이어집니다.
- 프로젝트 안은 **주제별 / 에피소드별** 두 보기입니다. 회의 결정사항·프로젝트 정보 전용 최상위 탭은 없습니다.
- 주제별은 공통 업무 유형 5개로 태스크를 묶습니다. 태스크를 열면 작업 내역이 바로 모두 보입니다.
- 에피소드는 작업 내역의 날짜와 시간을 **최신순**으로 표시합니다. 담당자·내용·관련 자료는 주제별 보기와 같은 데이터입니다.
- 화면 문구에 기획 의도 설명을 섞거나 상태·자료가 실제 외부 연동인 것처럼 표현하지 않습니다.

## 관련 자료

- 작업 내역의 자료까지 포함해 같은 `sourceId`로 연결합니다.
- 주제별로 묶고 그룹 안에서는 최신순입니다.
- 문서·저장소 배지, 이름, 출처, 날짜, 미리보기 버튼을 가진 행입니다.
- **약 4개가 보이는 400px 목록** 안에서 스크롤합니다. 자료 개수와 제목, 프로젝트 속성은 스크롤 목록 바깥입니다.
- 모든 자료를 목록에 넣고 스크롤로 접근합니다.
- 같은 프로젝트에서 보기 전환·재렌더링을 할 때 자료 스크롤 위치를 유지합니다.

## Activity·People

- Activity 하나가 최근 태스크를 담당합니다. 각 태스크의 최신 작업 내역 시각을 기준으로 정렬합니다.
- 태스크명, 프로젝트, 담당자, 날짜·시간을 표시합니다. 줄 간격은 약간 여유 있게 둡니다.
- Activity에는 ‘검토 필요’ 배지를 표시하지 않습니다. 별도의 최근 태스크 패널도 없습니다.
- People은 담당자별 참여 프로젝트 수를 표시하고 담당자 조회로 연결합니다.

## 타임라인

- 전체 목록과 각 펼친 프로젝트 안에 표시합니다. 내부에는 해당 프로젝트 한 줄입니다.
- 한 달의 1일부터 말일까지 표시하며 월 이동을 지원합니다. 주간 요약 주 선택과 독립적입니다.
- 태스크 생성~최근 작업 내역의 날짜 범위입니다. 예정 기간이나 진척률을 뜻하지 않습니다.
- 예시 기준일을 ‘오늘’ 선으로 표시합니다. 현재는 실제 시스템 날짜가 아니라 `demoAsOf` 기준입니다.
- AX 프로젝트는 2026-09-21부터 시작한 예시를 포함합니다. 월 경계 이전부터 이어진 기간을 화살표와 시작일로 표시합니다.

## 검토

- 프로젝트의 검토 요청은 전체 검토함으로 보내지 않고 **해당 태스크의 판단 영역**으로 이동합니다.
- 근거를 읽고 ‘맞아요 · 완료’ / ‘아니요 · 진행 중’을 선택합니다. 태스크 상태와 미확인 건수가 갱신되며 재선택할 수 있습니다.
- 프로젝트 전체 상태·진척률은 사용하지 않습니다. 상태는 위 판단이 있는 태스크에만 적용합니다.
- 검토 알림은 각 테마의 배경·강조색·테두리에 맞춥니다.

## 유지할 동작

검색·담당자 조회, 프로젝트 펼침, 작업 내역·관련 자료 연결, 월·주 이동, 테마 전환, 검토 판단, 이미지 미리보기, 브라우저 뒤로 가기, `/` 검색, Esc 닫기, 모달 키보드 포커스 처리를 보존합니다.
