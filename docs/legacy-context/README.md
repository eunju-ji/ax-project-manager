# 기존 기획 문서의 읽기 우선순위

## 최초 실행에서 반드시 읽기
1. `00_SERVICE_INTENT.md`: 목적과 기존 원칙
2. `01_SERVICE_FLOW.md`: 업무 처리 흐름과 역할 분리
3. `02_DATA_AND_EVIDENCE.md`: 원본 연결·동일 업무 판단·증빙
4. `03_OPEN_QUESTIONS.md`: 아직 해결되지 않은 질문. **답이 확정된 것으로 해석하지 말 것**
5. `04_IMPLEMENTATION_STATUS.md`: 현재 코드가 실제로 지원하는 범위

## 필요할 때만 읽기
- `05_UI_SPEC.md`: 기존 화면·디자인·상호작용을 검토하거나 수정할 때
- `06_DEVELOPMENT.md`: 기존 UI 설치·빌드·테스트·실행 시

이 폴더는 **과거 맥락의 근거 자료**입니다. 승인된 최신 결정은 `docs/decisions/`, 진행 상태는 `tasks/current-state.md`를 우선합니다. 새 프로젝트의 `CLAUDE.md`·`AGENTS.md`를 대체하지 않습니다.
