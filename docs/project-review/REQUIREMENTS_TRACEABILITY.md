## 수용 판정 기준

- **M3-01**은 SQLite 시작·롤백 검증에 더해 판단 경쟁, 응답 유실, 억제·이벤트·커서 계약, 백업 복원과 화면 회귀가 확인될 때 완료 판정한다.
- **파일럿**은 허용된 두 소스의 합의된 이벤트 범위, 중복과 누락 대조, 사람 교정 가능 여부, 권한 없는 접근 방지, 근거 추적을 검증한다. 자동 제안 정확도 목표는 합의 전이다.
- **초기 문서와 상태 조정**은 ADR-002(공수 후속), ADR-011(Drive·GitHub), ADR-013(DB 원본), [작업 상태](../../tasks/current-state.md)의 후속 Lead 기록에 근거한다. [기존 수용 기준](../05-acceptance-and-metrics.md) · [ADR 목록](../decisions/README.md)
