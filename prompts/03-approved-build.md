# 승인 후 구현 루프

사용자가 승인한 의사결정과 백로그 항목을 확인하라. 미승인 기능은 건드리지 마라. 다음 태스크 하나에 대해 입출력/관련 파일/수용 기준/테스트 계획을 작성하고, Paseo 프로필 `AX-Builder`로 `/paseo-handoff`하라. Builder는 추가 에이전트 위임 없이 구현·테스트하고 결과를 반환해야 한다. Lead가 변경 내용을 직접 검증하고 큰 변경만 `AX-Reviewer`에 `/paseo-advisor` 독립 검토 1회 요청하라. 수정은 최대 3번. 모든 결과를 `tasks/current-state.md`에 기록하라.
